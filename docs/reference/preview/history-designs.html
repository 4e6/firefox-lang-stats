Firefox language history

Five ways to show how the language mix changed across Firefox releases, for issue #10. Same data in every tab. Hover a chart for exact values, click the legend or controls to explore.

Sample dataLines of C++, Rust, C, JavaScript, HTML/CSS, Python, Java and Assembly in "All tracked files" and "Non-test files" are measured from 111 major releases (46 to 157; release 125 has no tag). The "Browser artifact" series (the code that ends up in the shipped browser) is made up to show the layout; it has not been collected for old releases yet.

What each design needs stored

Every design draws from one record per release: lines per language in each view. The x axis here is the version number (releases are about four weeks apart). A calendar-date axis would add one date field per release.
